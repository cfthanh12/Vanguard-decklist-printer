# Taste

## Workflow & scope

- Prefers minimal, unconstrained scope: doesn't want the tool to enforce domain rules or limits borrowed from other apps (e.g. copy limits, deck-format legality) — just the simple capability they asked for (add to list + filtering). Confidence: 0.55
- Prefers local, single-user tools ("my web app is just a tool for me") over deployable/multi-user apps — default to local-first scope unless they ask for a public site. When sharing, favors a self-contained "small tool" (one file to hand off) over an online hosted version, and expects "one click setup" with no Node/installer for the recipient. Confidence: 0.78
- Prefers autosave over manual save/open: wants work persisted automatically to local files so closing the window never loses it (chose an autosaving deck library over a manual save/open flow). Confidence: 0.55

## Product & UI

- For custom cards that aren't in the database, prefers them to print as a user-supplied picture (scan/proxy image) rather than a generated text card. Confidence: 0.8
